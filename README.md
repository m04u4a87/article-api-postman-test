# 文章 API 測試專案
針對文章管理功能(查詢、篩選、新增、修改、刪除)的 API，設計並執行測試案例，並用 Newman 自動執行，再產出 HTML 測試報告。

# 測試範圍
- 功能測試：正向、反向、邊界情境
- 工具：Postman、Newman、newman-reporter-htmlextra

# 測試案例
共 10 個。
| TC01 | 正向 | 查詢單篇文章 | 200，欄位完整 |
| TC02 | 反向 | 查詢不存在的文章 | 404 |
| TC03 | 正向 | 新增文章 | 201 |
| TC04 | 反向 | 新增文章（缺少資料） | 400 |
| TC05 | 正向 | 依作者篩選文章 | 200，共 10 筆 |
| TC06 | 正向 | 更新文章 | 200 |
| TC07 | 正向 | 刪除文章 | 200 |
| TC08 | 反向 | 查詢文章（編號為文字） | 404 |
| TC09 | 邊界 | 查詢最後一篇文章 | 200 |
| TC10 | 邊界 | 查詢超出範圍的文章 | 404 |

# 執行結果
10個請求、20個檢查點，其中1個失敗（TC04）。
