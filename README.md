# 文章 API 測試專案(Postman)
針對文章管理功能(查詢、篩選、新增、修改、刪除)的 API，設計並執行測試案例，並用 Newman 自動執行，再產出 HTML 測試報告。

## 測試範圍
- 功能測試：正向、反向、邊界情境
- 工具：Postman、Newman、newman-reporter-htmlextra

## 測試案例
- TC01：正向，查詢單篇文章
- TC02：反向，查詢不存在的文章
- TC03：正向，新增文章
- TC04：反向，新增文章(缺少資料)
- TC05：正向，依作者篩選文章
- TC06：正向，更新文章
- TC07：正向，刪除文章
- TC08：反向，查詢文章(編號為文字)
- TC09：邊界，查詢最後一篇文章
- TC10：邊界，查詢超出範圍的文章

## 執行結果
10個請求、20個檢查點，其中1個失敗（TC04）。
完整的測試案例表請見 [文章API測試模擬](article-api.postman.xlsx)

# 效能測試（JMeter）
使用 JMeter 對公開練習用 API 做小量負載測試，比較不同使用者數下的表現。

## 測試範圍
- 效能測試：小量負載測試
- 工具：JMeter

## 測試條件
- 測試對象：GET /posts/1
- 使用者數- 5、10、20 人
- 每人重複次數- 5
- 啟動時間- 5 秒

## 執行結果
- 三輪錯誤率皆為0%，吞吐量隨使用者數增加，系統在這個小量負載下沒有出現吃力的跡象。
- 完整的測試案例表請見 [JMeter負載測試模擬](jmeter/jmeter-summary.xlsx)
